# Books Notes

This folder stores structured notes derived from PDFs in `books/`, focused on actionable engineering outcomes.

## Purpose

- Convert book ideas into concrete implementation guidance.
- Link references to RFCs and code changes.
- Keep prompt/orchestrator decisions auditable.

## Source Books

- `books/Agentic-Design-Patterns.pdf`
- `books/Context-Engineering-for-Multi-Agent-Systems.pdf`
- `books/Designing-Multi-Agent-Systems.pdf`

## Note Files

- `books/notes/prompt-management-notes.md` - prompt architecture and governance notes
- `books/notes/TEMPLATE.md` - template for adding new notes

## Conventions

- Keep notes concise and implementation-oriented.
- Prefer sectioned bullets: insight -> implication -> action.
- Link to RFCs and code paths for each actionable item.
