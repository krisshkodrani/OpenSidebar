3. **Token waste reduction**: Strip bg-color/text-color from element output, deduplicate aria-label when matching text, raise NONE element cap 60→200
4. **Cross-step coherence check**: Layer 4 in auto-advance gate blocks done() when summary mentions wrong step
5. **done_rejected_no_read scoped**: Only enforced for multi-step plan tasks; planless tasks (summarize) can complete in 1 turn
6. **Fixture alignment**: dashboard (added email input + window global), navigation (fixed button/code/IDs), form (restructured to match test), errors (added window globals + element IDs)
