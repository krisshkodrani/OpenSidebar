# Phase 0 — Project Scaffold

> **Goal:** Set up the complete project skeleton so that `npm run dev` produces a loadable Chrome extension with a blank side panel, a no-op content script, and a service worker that logs "ready".

---

## Background

QSidebar is a Chrome Manifest V3 extension built with Vite + CRXJS (the `@crxjs/vite-plugin` package), React 18 for the side panel UI, and Tailwind CSS for styling. This phase produces a fully buildable, lintable, testable scaffold with zero business logic.

**Rationale for key choices:**
- `@crxjs/vite-plugin` v2 beta: Only version supporting Manifest V3 with HMR.
- `tailwindcss` v3 (not v4): v4 is stable but CRXJS compatibility is better tested with v3.

- `pdfjs-dist`: For extracting text from PDF files in the offscreen document.
- No test framework in deps — Bun has a built-in test runner.

**Permission justifications:**
| Permission | Reason |
|---|---|
| `sidePanel` | Required for the side panel UI |
| `activeTab` | Get info about the current tab |
| `tabs` | Query, create, close tabs across workspaces |
| `tabGroups` | Create and manage workspace tab groups |
| `storage` | Persist agent state, settings, workspace data |
| `webNavigation` | Detect page loads for the Navigation Bridge |
| `offscreen` | Create offscreen document for WASM memory worker |

## Build & Dev Commands

| Command | What it does |
|---|---|
| `npm run dev` | Starts Vite dev server with CRXJS HMR. Load `dist/` folder as unpacked extension. |
| `npm run build` | Runs `tsc --noEmit` for type checking, then `vite build` for production. |
| `npm run lint` | ESLint over `src/` with TypeScript rules. |
| `npm run test` | Bun test runner — discovers `tests/**/*.test.ts`. |
| `npm run fmt` | Prettier format all source files. |

## Edge Cases

- **CRXJS HMR port conflict:** If port 5173 is occupied, Vite will error. The `strictPort: true` config ensures a clear error instead of silently picking another port.
- **Windows path separators:** CRXJS handles path normalization internally. No special handling needed.
- **Node version:** Requires Node 18+. Vite 5 does not support Node 16.
