# Screenshots

This directory contains screenshots and GIFs for the OpenSidebar project.

## Image Specifications

- **Format**: PNG for screenshots, GIF for animations
- **Resolution**: 1920x1080 or similar (16:9 aspect ratio)
- **File size**: Keep under 1MB for PNGs, under 5MB for GIFs
- **Naming**: Use descriptive names with hyphens (e.g., `main-interface.png`)

## Required Images

1. `main-interface.png` - Side panel showing main chat interface
2. `element-tagging.png` - Webpage with visible yellow tags [1], [2], [3]
3. `settings-panel.png` - Settings drawer with API key configuration
4. `workspace-selector.png` - Workspace dropdown menu
5. `agent-demo.gif` - Screen recording of agent performing task

## Updating Images

When updating screenshots:

1. Use same filename to preserve links
2. Optimize images (use tinypng.com or similar)
3. Update this README if adding new images
