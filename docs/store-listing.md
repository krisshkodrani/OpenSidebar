## Full Description

```text
OpenSidebar - Open Source AI Browser Agent

OpenSidebar turns Chrome into an AI-powered browser workspace. Chat with the agent in a side panel and let it navigate pages, click buttons, fill forms, inspect state, and execute multi-step workflows.

What it does

- Navigate and interact with websites through natural language
- Fill forms and handle repetitive browser tasks
- Extract information from pages
- Run multi-step flows across tabs
- Record and replay common workflows

Current architecture

- Executor model: GPT-5.4 Mini via OpenRouter
- Planner model: GPT-5.4 Mini via OpenRouter
- Perception model: Grok 4.1 Fast via OpenRouter
- Visual perception layer for location, changes, blockers, visual-only cues, and affordances
- Planner -> executor -> verifier orchestration for harder tasks

Why it is different

- Open source (MIT)
- Bring your own OpenRouter key
- No subscription required
- Built-in traces, logs, and evals
- Plan confirmation and approval gates for sensitive work

You are in control

- Approve or reject risky steps
- Pause, resume, or stop at any time
- Review plans before longer runs
- Keep data in your own browser storage and provider account

Safety notes

Browser AI can still encounter prompt injection and confusing page state. Start with trusted sites, review sensitive actions, and use approvals for higher-risk operations.

Source code: https://github.com/krisshkodrani/OpenSidebar
```
