## Full Description

```text
OpenSidebar is an open-source AI browser agent for Chrome.

Use it from a side panel to navigate pages, click buttons, fill forms, inspect page state, and complete multi-step browser workflows.

What it does

- Navigate and interact with websites through natural language
- Fill forms and handle repetitive browser tasks
- Extract information from pages
- Run multi-step flows across tabs
- Show traces and logs for debugging

Why it is different

- Open source
- Bring your own provider key
- No subscription required
- Built-in traces and logs
- Plan confirmation and approval gates for sensitive work

You stay in control

- Approve or reject risky steps
- Pause, resume, or stop at any time
- Review plans before longer runs
- Keep data in your own browser storage and provider account

Safety notes

Browser AI can still make mistakes or misread page state. Start with trusted sites and review sensitive actions carefully.

Source code: https://github.com/krisshkodrani/OpenSidebar
```
